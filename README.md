# SOC Lab Notes

Hands-on security monitoring labs using Wazuh SIEM in a home lab 
environment (Windows 11 endpoint → Ubuntu-based Wazuh manager/
indexer/dashboard).

- [Lab 1: Brute Force Detection](./lab-01-brute-force-detection.md)
- [Lab 2: File Integrity Monitoring](./lab-02-file-integrity-monitoring.md)
- [Lab 3: Privilege Escalation Detection](./lab-03-privilege-escalation.md)
- [Lab 4: Custom Detection Rule](./lab-04-custom-detection-rule.md)
- [Lab 5: Active Response Investigation](./lab-05-active-response-investigation.md)
- [Lab 6: Vulnerability Detection & SCA](./lab-06-vulnerability-detection-sca.md)

## Skills Demonstrated
- SIEM deployment and administration (Wazuh, multi-machine architecture)
- Log analysis and alert triage (Windows Event Logs, FIM, correlation rules)
- Custom detection rule and decoder development (XML rule writing, debugging)
- MITRE ATT&CK mapping and coverage gap analysis
- Security Configuration Assessment (CIS benchmarks) and compliance mapping
- Threat intelligence integration concepts (VirusTotal, Active Response)
- Root-cause troubleshooting (XML syntax errors, service failures, network diagnostics)
